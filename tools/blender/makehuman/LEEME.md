# Recursos de MakeHuman

Malla base (`base.obj.gz`), objetivos de forma (`targets/`), esqueleto `default.mhskel`, pesos
`default_weights.mhw.gz` y ojos (`ojos/`) de MakeHuman 1.x (https://makehumancommunity.org). Los recursos de
MakeHuman se publican como dominio público (CC0 1.0). La textura del iris está recoloreada.

`mh.py` los lee directamente desde Blender, sin instalar MakeHuman.
